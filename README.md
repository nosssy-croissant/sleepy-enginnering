# sleepy-enginnering

エンジニアの睡眠の質向上のための思想・開発ポリシーをまとめるリポジトリです。（ネタ寄り）

## 背景

エンジニアの睡眠の質向上が求められている。  
利益を追い求める加速主義的な情勢と、それに伴う人類の疲弊を改善する必要があると考える。

## リポジトリの成果物

- 現状、`README.md` のみを作成し、内容を集約しておく。
- 展望として、Claude Skill の作成を検討する。

## 睡眠志向エンジニアリング・ポリシー

- 減速主義・非合理性を肯定する。
  - レイテンシは、スローな営みを肯定するための人生の余白である。
  - 安全側に倒すより、安眠側に倒れること。
- ブルーライトを発する機器の使用を原則禁止する。
- セキュリティ対策として、「攻撃者には永遠の眠りを提供する」と明記する。
- Web などで表示する広告は、寝具・書籍・アロマ・カモミールティー・マッサージなど、睡眠に寄与するものを表示する。
- Issue への返信は、ASMR・おとぎ話・夢小説などの形式で回答する。
